# Source attribution

The backend, dashboard and Gradio UI were adapted from the core `6_mcp` material in Ed Donner's `agents` repository, supplied locally as `Documents/GitHub/mcp`. The parent repository's MIT license and copyright notice are retained in LICENSE. No community contributions or original instructional notebooks are included.

This project adds standalone packaging; five project-specific solution notebooks; executable no-key and MCP protocol examples; isolated persistence paths; explicit fixture/simulated/live quote modes; validated orders and cash flows; corrected cash-flow-adjusted P&L and remaining-position cost basis; lazy optional provider initialization; a bounded agent runner; local-only summaries by default; regression tests; mobile dashboard layout fixes; and an updated frontend toolchain.

This is a documented adaptation. The inherited MCP architecture and UI are not claimed as original work.
